GLYPHCAST

GPU ASCII video engine
H.264 MP4 recommended. Decoded 100% locally.
Procedural test scene — proves the GPU engine works.
Picks each glyph by shape, not brightness. Off = fast ramp.
0 = flat color per cell (classic). 1 = full-resolution color, glyph keeps the shape.
Keeps last frame's glyph when scores are close. Kills shimmer in motion. 0 = off.
Emits the actual character grid, not pixels.
Walks every frame and writes a self-contained file that replays with no server. File size scales with cols squared — 480 cols is ~16x the data of 120.
Drop an MP4 here, click “Open MP4…”, or hit “Demo”.
